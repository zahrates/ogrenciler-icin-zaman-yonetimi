# Öğrenciler İçin Zaman Yönetimi ve Verimli Ders ÇalışmaTeknikleri

Bu proje öğrencilere çalışma vakitlerini daha kaliteli geçirmeleri için bir rehber niteliğinde hazırlanmıştır. 

-----------------------------------------------------------------

## 📌 Proje Amacı

Öğrencilerin dikkat dağınıklığını azaltmak, düzenli mola alışkanlığı kazandırmak ve çalışma verimliliğini artırmak.

- ⏱️ Pomodoro Timer (25/5 çalışma döngüsü)
- 🌙 Dark / Light mode desteği
- ✨ Scroll animasyon efektleri
- 📱 Responsive tasarım
- 🔗 Sayfa içi yönlendirme linkleri
